# E5577 Control

[English](#english) · [Italiano](#italiano)

## English

**E5577 Control v1.0.1** is a desktop application for managing and diagnosing a **Huawei E5577Cs-321** LTE pocket router. It provides connection/signal status, live traffic, read-only SMS, saved devices, LTE-band controls and a guarded network benchmark. Advanced telemetry depends on firmware capabilities; the application does not invent unavailable measurements.

**Developer:** [matt88.it](https://matt88.it) · **Source:** [GitHub](https://github.com/matteodurso88/e5577-control) · **Releases:** [GitHub Releases](https://github.com/matteodurso88/e5577-control/releases)

Linux x86-64 and Windows x86-64 have native installers and portable packages built by GitHub Actions. Packages are **unsigned**. No modem or cloud service is required for the offline test suite; real hardware operations require explicit connection and authorization.

## Italiano

**E5577 Control v1.0.1** è un'applicazione desktop per gestire e diagnosticare il modem LTE **Huawei E5577Cs-321**. Include stato della connessione e del segnale, traffico in tempo reale, lettura SMS, dispositivi salvati, controlli sulle bande LTE e benchmark di rete con verifiche preventive. I dati radio avanzati dipendono dal firmware: l'app non presenta misure non disponibili come se fossero reali.

**Sviluppatore:** [matt88.it](https://matt88.it) · **Sorgente:** [GitHub](https://github.com/matteodurso88/e5577-control) · **Release:** [GitHub Releases](https://github.com/matteodurso88/e5577-control/releases)

Sono previsti installer e pacchetti portabili per Linux x86-64 e Windows x86-64, costruiti con GitHub Actions. I pacchetti **non sono firmati**. I test offline non richiedono il modem né servizi cloud; le operazioni hardware richiedono collegamento e autorizzazione esplicita.
