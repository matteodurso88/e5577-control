E5577 Control v1.0.0 targets Linux x86-64 and Windows x86-64. Each OS build creates a native installer and a portable archive; the tagged workflow publishes the four packages with SHA-256 checksums **only when the release gate succeeds**. Artifacts are unsigned. The original WORKSHOP v0.1.0 packages remain preserved as historical evidence.
